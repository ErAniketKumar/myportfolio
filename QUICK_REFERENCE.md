## 🎨 Customization Quick Guide

### Change Main Color:

Find & Replace: `yellow-500` → `your-color-500`
Find & Replace: `yellow-400` → `your-color-400`
Find & Replace: `yellow-300` → `your-color-300`

Popular alternatives:

- Blue: `blue-500`, `blue-400`, `blue-300`
- Purple: `purple-500`, `purple-400`, `purple-300`
- Emerald: `emerald-500`, `emerald-400`, `emerald-300`

### Add More Projects:

Edit: `src/components/Projects.jsx`
Add to: `projects` array (line ~28)

### Update Skills:

Edit: `src/components/Skill.jsx`
Modify: `skillCategories` array (line ~15)

### Change Content:

Each component has clear sections - just find and update the text!
